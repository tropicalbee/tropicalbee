# Artwork briefs

Artwork was generated with the built-in image-generation tool. The bundled PNGs allow the project to render locally without an image service or API key.

## Pixel sprite atlas

Generate a transparent 5-column by 4-row sprite sheet of twenty technology items, following the supplied Halloween tech-display reference. Use strong silhouettes, chunky stair-step edges, flat color clusters, 3–5 shades per icon and small top-left highlights. Keep transparent gutters and holes. No frames, labels, soft vector edges, blur or ground shadows.

Row 1: Python, C++, HTML, CSS, PyTorch.
Row 2: FastAPI, Streamlit, scikit-learn, LangChain, LangGraph.
Row 3: Git, GitHub, Docker, VS Code, Jupyter.
Row 4: Firebase, ChromaDB, Supabase, Codex, Antigravity.

Keep the blue/yellow Python snakes, white C++ on blue hexagon, HTML shield with white 5, CSS shield with white 3, orange PyTorch flame-ring, teal FastAPI lightning, red Streamlit bird, and recognizable silhouettes for the other marks. Firebase uses its classic angular orange/yellow flame. Codex uses a pixel terminal cloud. Antigravity uses a flat-color pixel arch. Every item occupies the center of its equal cell.

## Full cobweb

Extract/recreate one chunky Minecraft cobweb from the reference beside the Languages sign. Use an irregular full web with a central hub, jagged radiating spokes and uneven cross strands. Use off-white/gray pixel clusters, transparent holes and a low-resolution texture enlarged cleanly. No geometric square border, regular quarter-circle diagram, smooth delicate lines, glow or ground shadow. Keep one isolated full cobweb on transparency.

## Final tall backdrop

Create a tall 2:3 version of the supplied outdoor Minecraft display, intended 1280 by 1920. Preserve its large block construction, dark oak, midnight navy sky, nearly-black forest, cracked stone pillars and heavy stone TECH STACK title. Use exactly five bays followed by solid stone foundation. Bays two and four are substantially taller for two rows of large items. Leave all back walls bare dark oak for editable signs and frames. Keep four carved pumpkins at the upper beam ends, outside left of bay three and outside right of bay five, with small gold carved cores. Hang two small amber lanterns below the top beam. Reserve upper-left sky for a native stepped circular moon. Do not add any other text, signs, frames, icons, ghosts, spiders or webs to the backdrop. Avoid fog, purple glow, sparkles, books, skulls, UI panels and extra shelves.

## Claude Code sprite

`pixel-icons/claude-code.png` is not generated. It traces the official Claude Code mark (#D97757) onto its own 16 by 10 block grid, drawn 5 pixels per block with lighter top-left and darker bottom-right edge blocks, like the atlas sprites. The eyes remain transparent.

## Assembly

The five readable category signs, twenty-one frames and labels, moon and animations are added in editable source. Ghost and spider assets are shared with the earlier Welcome and Resident sections.
